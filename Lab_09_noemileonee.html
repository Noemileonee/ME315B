Atividade 02: Relação entre peso (carat) e preço (price)

grafico_1 = (
    ggplot(diamonds, aes(x="carat", y="price"))
    + geom_point(alpha=0.18, size=1)
    + geom_smooth(method="loess", se=False, color="#D55E00", span=0.5)
    + labs(
        title="Relação entre peso e preço dos diamantes",
        subtitle="Cada ponto representa um diamante",
        x="Peso (quilates)",
        y="Preço (dólares)",
        caption="Fonte: conjunto de dados diamonds"
    )
    + theme_minimal()
    + theme(figure_size=(9, 5))
)

Atividade 03: A relação entre peso e preço é igual para todos os cortes?

Para comparar os tipos de corte, vamos separar o gráfico em painéis. Assim, cada categoria de cut terá seu próprio painel, mantendo a mesma escala para facilitar a comparação.

grafico_2 = (
    ggplot(diamonds, aes(x="carat", y="price"))
    + geom_point(alpha=0.16, size=0.8)
    + geom_smooth(method="loess", se=False, color="#0072B2", span=0.5)
    + facet_wrap("~cut", ncol=3)
    + labs(
        title="Peso e preço por qualidade de corte",
        x="Peso (quilates)",
        y="Preço (dólares)"
    )
    + theme_minimal()
    + theme(figure_size=(11, 8), subplots_adjust={"wspace": 0.15, "hspace": 0.25})
)

Concluimos que os gráficos permitem explorar a associação entre peso e preço e comparar como ela se apresenta em diferentes categorias de corte, cor e clareza. O uso de transparência reduz a sobreposição dos pontos; os painéis facilitam a comparação entre categorias; e as curvas suavizadas ajudam a visualizar tendências que podem não ser lineares. Ao mesmo tempo, o grande número de observações e categorias dificulta a leitura de algumas comparações. Portanto, as visualizações ajudam a identificar padrões, mas não demonstram, por si só, causalidade nem a significância estatística das diferenças.
